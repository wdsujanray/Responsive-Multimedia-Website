# Responsive Multimedia Website

A modern, fully responsive multimedia playground built with **HTML, CSS, and vanilla JavaScript**. It showcases image zoom, audio visualizer with playlist, HD video, CSS heart animation, and an interactive particle canvas — all in one elegant page.

---

## ✨ Features

- **🖼️ Image Zoom Popup** — Click any image to view it in a full-screen, blurred backdrop modal. Close with a click or `Esc`.
- **🎵 Audio Player + Visualizer** — Real-time frequency bars react to the music. Includes a playlist with multiple tracks.
- **🎬 HD Video** — Clean, heavy-framed video player with full controls, muted autoplay-friendly, and loop.
- **❤️ Heart Animation** — Pulsing heart with falling hearts, rotating dashed ring, and a burst effect on click. Plays a short tune and displays the name **"Sujan Chandra Ray"** in glowing SVG text.
- **🖌️ Interactive Canvas** — Move your mouse or touch to draw glowing particles with smooth physics and trailing effects.
- **📱 Fully Responsive** — Adapts beautifully to mobile, tablet, and desktop screens.
